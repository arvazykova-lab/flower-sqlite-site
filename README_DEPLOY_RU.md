# Публикация сайта

1. Распакуйте архив.
2. Загрузите содержимое папки `site` в новый GitHub-репозиторий.
3. В Render выберите создание Web Service и подключите репозиторий (или используйте Blueprint по файлу `render.yaml`).
4. Build command: `pip install -r requirements.txt`.
5. Start command: `gunicorn app:app`.

В проекте SQLite-файл `db.sqlite` включён в репозиторий и доступен приложению. На бесплатном хостинге локальная файловая система может быть временной: изменения базы могут исчезнуть при пересборке/перезапуске. Для постоянного хранения данных потребуется постоянный диск или внешняя база данных.
